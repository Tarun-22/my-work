# Portfolio Next.js

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern design with gradient backgrounds and glass morphism effects
- 📱 Fully responsive design
- ⚡ Built with Next.js 14 and TypeScript
- 🎭 Smooth animations and transitions
- 📧 Contact form with validation
- 🚀 Optimized performance

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Add your background network image:
   - Place your `bg-network.png` image in the `public` folder

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

### Personal Information
Update the following files with your personal information:
- `components/Hero.tsx` - Your name and description
- `components/Contact.tsx` - Your email and social links
- `app/layout.tsx` - Site metadata

### Content
- `components/Skills.tsx` - Add your skills and technologies
- `components/Projects.tsx` - Add your projects
- `components/Certifications.tsx` - Add your certifications

### Images
Place your images in the `public` folder:
- `bg-network.png` - Background network image
- Project images for the portfolio section

## Build for Production

```bash
npm run build
npm run start
```
